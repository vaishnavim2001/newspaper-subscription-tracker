# Apartment Newspaper Subscription Tracker

A full-stack web application for managing newspaper and magazine subscriptions across apartments in a residential complex.

## Tech Stack

- React + Vite
- Node.js + Express
- PostgreSQL
- JWT Authentication
- Redis
- REST API

## Features

- Admin and Resident roles
- Apartment-wise subscription management
- Monthly bill calculation
- Subscription cancellation
- Redis caching
- CI/CD (planned)
